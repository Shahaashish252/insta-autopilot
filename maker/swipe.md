# Hook formulas working in the niche now

- **Matra-add fix (most promising).** Shape: "[शब्द] में एक मात्रा जोड़ो, [नया शब्द] बन जाओ।" The biggest niche outlier, 53.7× its own account's usual views (_navaratan_, 71k followers), was a caption built on this idea. It travels because the viewer can do the fix in their head, and the payoff is a new meaning. We already have this on मन → मान, so it fits our channel.
- **Word-play question.** Shape: "[बड़ी चाहत] चाहिए, तो [सरल शब्द] कैसे?" A question built on two similar-sounding words, which makes the viewer finish the thought themselves. It sits close to our channel's style, and the reel beat its account's usual views by 2.06×.
- **Virtue command.** Shape: "[गुण] रखना सीखो।" It got 6.57× on a 71k account, because it is a short, gentle reminder that is easy to send to someone. Caution: our own सब्र → सब reel got only 191 views, so the theme alone isn't enough. The outcome has to be shown in the hook.
- **Nostalgia question.** Shape: "[अपनी जगह/चीज़] को कितना याद करते हो?" Got 4.62× for the same account. It works because people comment and share a feeling that belongs to them. We haven't tried it.
- **Simple-definition line.** Shape: "[सुख/सफलता] तो [छोटी आदत] में है।" Got 3.02×. A short, quotable claim that reads like a saved line.
- **Seasonal question.** Shape: "[त्योहार] पर [सवाल]?" Got 2.48× and, with a plain festival greeting, 3.4×. It travels because the moment is shared by everyone. Time-limited, so use it only while the season lasts.
- **Protect-your-money warning.** Shape: "[जोखिम] से दूर रहो, [अपनी चीज़] बचाओ।" Got 2.3×. It is a protective warning that people forward to someone they care about. Note that our own "stop" hook on धन → धुन did poorly, so test it carefully.
- **Dedication series.** Shape: "[दिन N]/100 — उन दोस्तों के नाम जिन्हें लगता है [अकेलापन/भावना]।" Seen on a very small account (1,149 followers) at about 2.3-2.4×. A running counter plus a named audience brings people back. It is a weaker hint because the account is so small.
- **Caveats on all of the above:** this is caption-only data, so we can't see the hooks inside the videos. One account supplies most of the outliers, and each multiple is measured against that account's own usual views, not against ours.
